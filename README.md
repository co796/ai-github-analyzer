# AI GitHub Analyzer

AI GitHub Analyzer is a lightweight Python project for analyzing public GitHub repositories.

## Features

- Repository statistics
- Language detection
- Commit activity overview
- Contributor analysis
- Export results to JSON

## Stack

- Python 3.10+
- Requests
- GitHub REST API

## Installation

```bash
git clone https://github.com/co796/ai-github-analyzer.git
cd ai-github-analyzer
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```
